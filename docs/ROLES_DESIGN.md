# 📋 系统角色设计说明

## 🎯 根据毕业设计任务书定义

本系统包含 **两个核心角色**，符合毕业设计任务书要求。

---

## 1️⃣ 普通用户（微信粉丝）

### 角色定义
- **身份**: 微信公众号关注者
- **标识**: 微信 OpenID
- **存储表**: `wechat_user`

### 主要功能
✅ **关注公众号**
- 触发关注事件
- 自动接收欢迎语

✅ **发送消息**
- 文本消息
- 图片消息
- 语音消息
- 视频消息
- 位置消息
- 链接消息

✅ **接收自动回复**
- 关键词回复
- 关注自动回复
- 默认回复
- 按消息类型回复

✅ **查看历史记录**
- 通过微信客户端查看历史消息

### 技术实现
```java
// 无需后台登录
// 通过 open_id 唯一标识
// 消息处理流程：
// 1. 微信用户发送消息
// 2. 微信服务器转发到系统
// 3. 系统匹配回复规则
// 4. 返回回复消息给微信用户
```

### 数据示例
```sql
INSERT INTO wechat_user (open_id, nickname, subscribe) 
VALUES ('oXXXX-XXXXXXXXX', '微信用户', 1);
```

---

## 2️⃣ 运营者（管理员）

### 角色定义
- **身份**: 后台管理系统用户
- **标识**: 用户名 + 密码
- **存储表**: `sys_user`
- **角色代码**: OPERATOR

### 主要功能
✅ **登录后台**
- 用户名密码认证
- JWT Token 鉴权
- Session 管理

✅ **配置回复规则**
- 新增回复规则
- 编辑回复规则
- 删除回复规则
- 启用/禁用规则
- 设置优先级
- 测试规则匹配

✅ **管理用户**
- 查看微信粉丝列表
- 查看用户详情
- 查看互动记录
- 添加用户备注
- 用户标签管理

✅ **查看统计数据**
- 消息数量统计
- 规则命中统计
- 用户增长趋势
- 互动频率分析

✅ **公众号配置**
- 配置 AppID
- 配置 Secret
- 配置 Token
- 配置 AES Key
- 刷新 Access Token

### 技术实现
```java
// 需要登录认证
@RestController
@RequestMapping("/admin")
@PreAuthorize("hasRole('OPERATOR')")
public class AdminController {
    // 所有后台管理接口
}
```

### 数据示例
```sql
-- 默认运营者账户
INSERT INTO sys_user (username, password, role, status) 
VALUES ('admin', '$2a$10$...', 'OPERATOR', 1);

-- 密码：admin123 (BCrypt 加密)
```

## 💡 典型使用场景

### 场景 1: 用户咨询

1. **普通用户**在微信发送："你好"
2. 系统接收到消息
3. 匹配关键词规则（包含"你好"）
4. 返回预设回复："您好！欢迎关注～"
5. **运营者**可以在后台查看这条消息记录

### 场景 2: 配置新规则

1. **运营者**登录后台
2. 进入"回复规则"页面
3. 点击"新增规则"
4. 配置规则：
   - 规则名称：问候语
   - 匹配内容：你好
   - 回复内容：您好！有什么可以帮助您的？
5. 保存并启用
6. **普通用户**发送"你好"时收到新回复

### 场景 3: 查看统计

1. **运营者**进入"数据统计"页面
2. 查看今日消息量：1000 条
3. 查看热门规则：问候语（命中 300 次）
4. 查看新增粉丝：50 人
5. 根据数据优化回复策略

## 📝 数据库设计

### sys_user 表（运营者）
```sql
CREATE TABLE `sys_user` (
    `id` BIGINT PRIMARY KEY,
    `username` VARCHAR(50) NOT NULL,
    `password` VARCHAR(255) NOT NULL,
    `nickname` VARCHAR(50),
    `role` VARCHAR(20) DEFAULT 'OPERATOR',
    `status` TINYINT DEFAULT 1
);
```

### wechat_user 表（普通用户）
```sql
CREATE TABLE `wechat_user` (
    `id` BIGINT PRIMARY KEY,
    `open_id` VARCHAR(100) NOT NULL,
    `nickname` VARCHAR(100),
    `subscribe` TINYINT DEFAULT 0,
    `interaction_count` INT DEFAULT 0
);
```
